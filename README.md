# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/0db3bad2-1d37-4228-9c15-247dfa21aead

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
   The project npm configuration retries transient registry failures automatically.
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
